# Ludora

Site de présentation de **Ludora**, un launcher de jeux qui rassemble dans une seule bibliothèque les jeux de huit plateformes (Steam, Epic Games, GOG, Ubisoft Connect, EA app, Battle.net, Riot Games, Xbox), ceux installés hors plateforme et, avec le Conservatoire, ceux des anciennes consoles.

Site en ligne : https://fv-1.github.io/ludora/

Projet de Victor Falc'hun. Les jaquettes de jeux proviennent des fiches Steam officielles et appartiennent à leurs éditeurs. Logos de marques : [Simple Icons](https://simpleicons.org/) (CC0), marques appartenant à leurs titulaires.
